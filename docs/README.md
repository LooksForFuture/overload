# Docs

The game follows a unity inspired compnent design. There are entities, and components.
I don't spend time explaining what entities and components are. You can read for yourself by searching for "What are unitty game objects and components", "What is an ECS", ... The difference between my approach(and unity's) with ECS, is that the components not only have data, but also behavior.
